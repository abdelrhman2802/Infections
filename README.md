# Colony — Infectious Diseases MCQ
React 19 + Vite + Framer Motion + Lucide.

    npm install
    npm run dev      # local
    npm run build    # outputs dist/ (static, relative paths)

Deploy `dist/` to Netlify, Vercel, GitHub Pages or any static host.
Questions live in `src/data.json`. Favorites, notes and theme persist in localStorage.
